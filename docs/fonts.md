# Fonts

Registry: `fonts/registry.json` (generated by `python -m dataset.fonts.scan`).
Bundled OFL: Noto Sans/Serif Bengali, Hind Siliguri R/M/B, Inter.
API: `FontRegistry.get(language, family, weight, size)` → `(font, meta, fallback_record)`.
Missing fonts never fail silently — fallback recorded in `metadata/*.json → fallbacks`.
Distribution: `configs/fonts.yaml`. Bengali shaping: use HTML renderer for exact
HarfBuzz shaping (Pillow here lacks raqm).
